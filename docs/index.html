Transferable agent skills · Multi-objective evolution

One skill version is rarely best for every deployment.

ParetoSkill evolves trajectory-grounded patches into an auditable portfolio of agent skills, balancing accuracy, cross-target transfer, token cost, and the risk of breaking behavior that already works.

Research question

How should reusable skills evolve when improvements can also regress?

A patch can repair failures on its source task yet add context cost, break a previously solved task, or fail under another model, harness, or domain. Selecting only by source validation accuracy hides these deployment trade-offs.

ParetoSkill treats each version as a multi-target, multi-objective candidate and preserves the useful non-dominated alternatives instead of collapsing them into one fixed utility score.

Optimization objectives

A deployment-facing frontier

01

ID accuracy

Success on held-out tasks from the source distribution.

02

Worst-target transfer

Robustness across model, harness, and out-of-domain groups.

03

Token cost

Skill injection and execution overhead measured per task.

04

Paired regression

The chance that a candidate breaks a task solved by the base skill.

Evaluation

Designed to make the narrower claim falsifiable.

✓ Matched candidate-evaluation budgets across baselines
✓ Spreadsheet tasks plus out-of-distribution table reasoning
✓ Heterogeneous model and agent-harness targets
✓ Frontier quality, false admissions, and paired regressions
✓ Passive-archive and uncertainty-aware ablations
